# Luka-HTB-Writeups
Practical penetration testing writeups, enumeration modules, pwntools templates, and pentest reports — HTB Labs/Modules

Purpose:
- Showcase hands-on skills for recruiters and employers
- Track learning progress in a reproducible way
- Provide practical resources and templates for other learners

Structure:
- `writeups/` — full machine writeups (markdown + PoC code + screenshots)
- `modules/` — module summaries (Nmap, enumeration, web exploitation, AD)
- `tools/` — short scripts and exploit templates
- `reports/` — pentest report templates and completed example reports
